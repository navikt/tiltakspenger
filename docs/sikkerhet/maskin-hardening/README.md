# Maskin-hardening

Oppskrifter for å herde utviklermaskinen.
Fellesnevneren er at hemmeligheter og nøkler skal ligge i maskinvare og kreve at et menneske er til stede, framfor å ligge som filer en prosess kan lese.

- [Signerte commits (macOS)](signerte-commits-mac.md) — Secure Enclave via Secretive. Testet.
- [Signerte commits (Linux)](signerte-commits-linux.md) — FIDO2-sikkerhetsnøkkel. **Ikke testet.**
