# KI-agenter

Oppskrifter for å kjøre KI-agenter isolert på utviklermaskinen.
Kravet står på [ki-utvikling.nav.no](https://ki-utvikling.nav.no/nyheter/sandboxing-er-pakrevd-pa-nav-utstyr), og på macOS og Linux dekkes det av [cplt](https://ki-utvikling.nav.no/cplt) rett fra Homebrew.
Det som trenger en egen oppskrift, er plattformene cplt ikke finnes for.

1. [Sandboxet agent på Windows](sandboxing-windows.md) — Copilot CLI og cplt inne i WSL2, siden cplt ikke finnes for Windows og Copilots innebygde sandbox der krever et Insiders-bygg. **Ikke testet.**
